# Code of conduct

Pace is a small project. A few rules keep it pleasant.

- Be kind and assume good intent.
- Criticize code and ideas, not people.
- No harassment, insults or personal attacks, in issues, pull requests or anywhere else connected to the project.
- Never post anyone's tokens, account details or private information, including your own.

Maintainers may edit or remove comments, close threads and block accounts that break these rules.

To report a problem privately, use the **Report a vulnerability** button on the repository's Security tab and say it is a conduct report.
