# Changelog

## 0.4.0

First public release.

- **Panel.** Session used and time until reset side by side, a pace forecast, and a list of the week, model limits, credits and usage by product. Time is shown in hours and minutes.
- **Details on click.** Rows open to show an even-pace marker, the day of the week and a daily budget. Several can be open at once.
- **Status pill.** A small capsule under the menu bar icon announces each change once: limit reached, limit back, running fast.
- **Two data sources.** A Claude Code status line script with no credentials, or the Claude Code sign-in, read only.
- **Everyday use.** Starts at login, opens with a shortcut you can record, right-click menu with Quit.
- **Safety.** The sign-in is never written, renewed or logged. Requests go to one host, with no cache and no redirects. The status line installer backs up and restores your settings.
